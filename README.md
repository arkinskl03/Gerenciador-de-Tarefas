Gerenciador de Tarefas em Java

Aplicação de console em Java puro para gerenciar tarefas: adicionar, listar, concluir e remover. Projeto de estudo focado em Programação Orientada a Objetos e coleções.

Funcionalidades
Adicionar uma tarefa com título
Listar todas as tarefas com seu status
Marcar uma tarefa como concluída
Remover uma tarefa pelo ID
